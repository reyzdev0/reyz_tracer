# Reyz Tracer Simulation 🌐📱

**Reyz Tracer Simulation** adalah aplikasi simulator dan visualisasi jaringan interaktif berbasis Android yang dibangun menggunakan **Flutter**. Aplikasi ini dirancang untuk membantu pelajar, mahasiswa, dan penggiat jaringan dalam mempelajari konsep dasar jaringan, konfigurasi perangkat, simulasi paket data, serta integrasi perangkat IoT secara visual dan praktis di perangkat seluler.

---

## 🚀 Fitur Utama

- **Canvas Topologi Interaktif:** *Drag & drop* perangkat jaringan dengan mudah langsung dari layar HP.
- **Simulasi Perangkat Lengkap:**
  - Perangkat Jaringan: Router, Switch, Hub, Access Point (AP), WLC.
  - End Device: PC, Laptop, Server, Smartphone, Printer, IP Phone.
  - Perangkat IoT: Smart Lamp, Switch Sensor, Motion Detector, Alarm, IoT Gateway.
- **Mode Tema:** Mendukung beberapa tampilan tema warna (Dark Mode, OLED Black, dan Light Mode).
- **Pengaturan & Alat (Tools):**
  - Tool Select, Hand (Pan Canvas), Delete, Inspect, Note, Ping, dan Cable/Koneksi.
- **Mobile-Friendly CLI & Config:** Konfigurasi antarmuka dan perangkat dengan kontrol sentuh yang responsif.

---
